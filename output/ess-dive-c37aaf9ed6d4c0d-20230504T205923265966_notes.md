# Harmonization notes — dataset index 27

**Dataset:** `ess-dive-c37aaf9ed6d4c0d-20230504T205923265966`
**DOI:** doi:10.15485/1788230
**Title:** Continuous sensor suite measurements of weather, energy, soil and flux at four PumpHouse sites at the East River, Colorado (WFSFA SFA).

## Decision: INCLUDE

The package contains direct soil-moisture observations from a continuous
sensor suite deployed on tripods at four East River PumpHouse stations
(ER-PHS1–ER-PHS4). Both harmonizable soil-moisture quantities are present:

- **Volumetric water content** (Teros12 sensors S1–S4), already in m³ m⁻³.
- **Soil matric / water potential** (MPS6 / TEROS 21 sensor S5), already in kPa.

Decision rules applied (SKILL SECTION 3):
- Rule 1 (duplicate/superseded): not triggered — this is the current record.
- Rule 2 (measurement type): passes — direct VWC and matric-potential observations.
- Rule 3 (experimental manipulation): none; ambient monitoring stations.
- Rule 4 (extractable payload): passes — four machine-readable time-series CSVs.
- Rule 5 (minimum metadata): site identifiers (ER-PHS1–4) are traceable to the
  East River watershed; coordinates themselves are unresolvable here (see below).

## Payload identification

Only the four `ER-PHS*_Field*.csv` files are staged and used as measurement
payloads. The ESS-DIVE metadata record lists additional files not staged in
this workspace (Excel duplicates of the CSVs, a field-note PDF/DOCX, and
`ER-PHS_Metadata Despription.xlsx/.csv`). These were not available as inputs
and are not required: the CSVs carry the full measurement payload.

## Variable mapping

Each file is one site (`site_id` = ER-PHS1 … ER-PHS4). Soil channels, from the
package `measurementTechnique` field notes (Oct 8 2019 installation):

| Channel | Variable | Depth |
|---------|----------|-------|
| S1 `*_wc_(m3/m3)` | VWC | 115 cm (**106 cm at ER-PHS4**) |
| S2 `*_wc_(m3/m3)` | VWC | 60 cm |
| S3 `*_wc_(m3/m3)` | VWC | 30 cm |
| S4 `*_wc_(m3/m3)` | VWC | 10 cm |
| S5 `*_wp_(kPa)`   | water potential | 30 cm |

- VWC: no unit conversion (source already m³ m⁻³). Wide→long melt of S1–S4.
- Water potential: no unit conversion (source already kPa, negative).
- `gravimetric_water_content_gH2O_gs`: not measured → NaN.
- `replicate`: 1 (single sensor per site/depth/channel).

## Time series determination

`is_timeseries = True`. These are continuous logger deployments with regular
hourly timestamps spanning Oct 2019–Apr 2020 (the single-day ER-PHS3 file is
also sensor output from the same deployment).

## Timestamp handling

Source `Time` is local Mountain Time, parsed with `%m/%d/%Y %H:%M` and
converted from `America/Denver` to UTC (e.g. 2019-10-11 14:00 MDT →
2019-10-11T20:00:00Z). DST transitions handled via the shared tz-localize
convention (`ambiguous="NaT"`, `nonexistent="shift_forward"`).

## Missing-value handling

- The water-potential column uses `-99999` as a missing-value sentinel; these
  are converted to NaN. The **ER-PHS4 S5 channel is entirely `-99999`**, so no
  valid water-potential observations exist for ER-PHS4.
- Rows with no valid VWC and no valid water potential are dropped.
- No `-9999` sentinels were present in the VWC columns.

## Location resolution — qc_flag = g2 (coordinates unresolvable)

No per-site coordinates are available anywhere in this workspace:
1. Not in the payload CSVs.
2. No ancillary location file is staged (`ER-PHS_Metadata Despription.*` is not
   present as an input).
3. The cached ESS-DIVE package metadata gives only a **watershed-level bounding
   box** (NW 39.034,−107.05; SE 38.88,−106.88), not per-station coordinates.
4. The authoritative registry the package points to — Varadharajan et al. 2020
   "Location Identifiers … East River Watershed" (doi:10.15485/1660962) — is
   **not staged** in this workspace.

Per SKILL SECTION 5, coordinates are therefore not resolvable. Every `site_id`
is emitted in `*_location.csv` with empty `latitude`/`longitude` and
`qc_flag = g2`. No coordinates were invented.

## Output summary

- Harmonized rows: 49,081 across 4 sites (ER-PHS1 15,483; ER-PHS2 17,051;
  ER-PHS3 35; ER-PHS4 16,512).
- VWC observations: 48,752; water-potential observations: 329 (none at ER-PHS4).
- Depths present: 0.10, 0.30, 0.60, 1.06 (ER-PHS4 S1), 1.15 m.

## Open questions / limitations for operator review

1. **Coordinates (g2):** could be upgraded to g1 if the Varadharajan 2020
   location registry is supplied; the four PumpHouse stations have known
   coordinates there.
2. **ER-PHS4 S1 depth:** set to 1.06 m per the field-note exception; all other
   S1 channels at 1.15 m.
3. **ER-PHS4 water potential:** entirely sentinel-valued; retained the site but
   it contributes no water-potential rows.
4. A small number of very negative but non-sentinel water-potential values
   (e.g. −13854.6 kPa) were retained as plausible very-dry MPS6 readings.
