# Harmonization notes — dataset 17

- **Dataset identifier:** `ess-dive-be919d7d5d42c94-20240130T205332180`
- **DOI:** `doi:10.15485/2283406`
- **Canonical index:** 17 (retained from `MANIFEST.json`; not reassigned)
- **Title:** Geophysical and Environmental Monitoring Data, and Subsurface Flow
  Modelling Results for Chicken Bone Meadow, Mt. Snodgrass, Crested Butte, CO
  (Watershed Function SFA, East River watershed).

## Decision: INCLUDE

- **Rule 2 (measurement type):** PASS. Files contain direct volumetric water
  content observations from Teros 12 sensors (`MC_*` columns, units V/V).
- **Rule 4 (extractable payload):** PASS. Five per-site CSVs with hourly,
  time-stamped measurement tables.
- **Rule 5 (minimum metadata):** PASS. `Locations.csv` provides sensor
  coordinates in UTM Zone 13N.
- Rules 1 (duplicate/superseded) and 3 (manipulation) not triggered: this is an
  ambient monitoring transect; the superseding-version check cannot be run from
  within this fold workspace (only this record is supplied) — no evidence of
  duplication was available to act on.

## Payload identification

- **Payload (soil moisture):** `FieldData/Soil_Moisture_Data/TMC{1,2,4,5,6}.csv`
  — wide-format hourly time series. Each file has a header row plus a second
  units row (`V/V`, `degrees_Celsius`, `mS/cm`); the units row is skipped on read.
- **Excluded columns:** `T_*` (soil/snow temperature) and `EC_*` (electrical
  conductivity) are not soil-moisture observations and are dropped.
- **Location ancillary:** `Locations.csv` (`ID`, `Easting`, `Northing`,
  `Elevation`, `Type`).
- Other package contents (ERT geoelectrical data, borehole/groundwater, weather,
  PFLOTRAN modelling results, `dd.csv`, `flmd.csv`) are out of scope for soil
  moisture and were not staged as data payload.

## Time-series determination

`is_timeseries = True`. Metadata describes 15-min logger acquisition averaged to
hourly values; each site+depth has many timestamped records (SKILL Section 4).

## Location resolution (SKILL Section 5)

- Source: package ancillary file `Locations.csv` (priority level 2).
- CRS: metadata states NAD83 – UTM Zone 13N; reprojected EPSG:32613 → EPSG:4326
  via the project `utm32613_to_latlon` helper.
- All five data-bearing sites resolved → `qc_flag` empty (no `g1`/`g2`).
  Resolved coordinates fall inside the package's reported spatial-coverage
  bounding box (NW 38.926497/-106.981785, SE 38.92556/-106.979327).
- `TMC3` appears in `Locations.csv` but has **no** soil-moisture data file, so it
  is excluded from both outputs. Non-soil-moisture entries (ERT, borehole,
  weather station) are also excluded from the location file.

## QA checks (SKILL Section 9)

- Schema: all 8 harmonized columns present and in canonical order.
- Units: VWC left unconverted (V/V = m³ m⁻³); depth already in meters.
- Timezone: all timestamps converted to UTC.
- Missing values: rows with non-parseable/NaN VWC or datetime dropped.
- Output: 225,544 harmonized rows; VWC range 0.0–0.4549.
- Location file: one row per site_id with `site_id,latitude,longitude,source_dataset_id,qc_flag`.
- Index: canonical index 17 retained.

## Environment / limitations

- `pandas` and `pyproj` were not pre-installed; both were installed into the
  workspace to run the transformation. The `utm32613_to_latlon` helper requires
  `pyproj`.
- Timezone `Etc/GMT+7` (fixed MST, no DST) chosen to match the expert convention
  used for other East River / Crested Butte hourly sensor datasets (e.g.
  datasets 1, 16, 25). If the logger recorded in local clock time with DST, a
  small seasonal offset could exist; metadata does not state the logger clock
  convention explicitly.
