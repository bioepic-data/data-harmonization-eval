Canonical index (from MANIFEST.json): **2**

Title: Soil moisture and temperature data along the northeast facing hillslope at
the Lower Montane site in the East River Watershed, Colorado (Dafflon & Leger, 2021).

## Payload identification
- **Measurement payloads (4):** `ER_SMN1.csv`, `ER_SMN3.csv`, `ER_SMN4.csv`,
  `ER_SMN5.csv`. Each is one sensor location (5TE sensors, Decagon) with soil
  moisture, temperature, and EC at 10 and 50 cm, in wide format.
- **Location/ancillary (1):** `SM_loc.csv` — site names, UTM13N coordinates,
  elevation, sensor type, and decimal-degree Lat/Lon.
- Note: there is no `ER_SMN2.csv`; the package ships sites SMN1, SMN3, SMN4, SMN5.

## Inclusion decision
**INCLUDE.** Dataset contains direct volumetric water content observations
(m3/m3) from in-situ sensors (Rule 2 satisfied). Payloads are machine-readable
time-stamped tables (Rule 4). Coordinates are present in the package (Rule 5).
No evidence of experimental manipulation (ambient hillslope monitoring, Rule 3).
Not a superseded/duplicate package of any included exemplar (Rule 1): the
2019–2024 continuation is a separate archive (doi:10.15485/2566877) and is not in
scope here.

## Units & cleaning
- VWC units are already m3/m3 per package `measurementTechnique`; no conversion.
- Depth: divide cm by 100 to get meters.
- No-data sentinel `-9999` (documented in package metadata) replaced with NA.
  Affected VWC cells: 23,086 of 154,242 rows (sensor failures from wildlife
  damage / snowmelt connectivity loss noted in the package description).

## Time-series determination
`is_timeseries = True`: continuous 5TE sensor deployment producing repeated
timestamped observations per site+depth (Section 4 rule).

## Location resolution (Section 5 priority order)
Priority 2 — coordinates taken directly from package ancillary file `SM_loc.csv`
(decimal-degree `Lat`/`Lon` columns). All four sites resolved, so no `g1`/`g2`
flag is applied (`qc_flag` left empty). UTM13N `Northing`/`Easting` columns are
also present and agree with the provided Lat/Lon; the reported Lat/Lon were used
directly. Package-level metadata only provides a bounding box, consistent with
the per-site coordinates.

## Open questions / limitations
- Timezone assumed Etc/GMT+7 (MST, no DST), consistent with other East River
  Watershed exemplars (datasets 5, 7, 8, 23, 25). The package does not state the
  timezone explicitly.
- `depth_m` is the exact installed sensor depth (10/50 cm), not an approximated
  range, so no `d1` flag is applied.
- No sensor replacement/relocation records; the 2019 repairs fall outside this
  package's temporal coverage (2016–2018) and do not affect these records.
