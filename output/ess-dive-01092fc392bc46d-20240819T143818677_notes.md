# Harmonization notes — dataset index 10

- **Dataset:** `ess-dive-01092fc392bc46d-20240819T143818677`
- **DOI:** doi:10.15485/2322567
- **Title:** Hydrological control of chemical weathering and rock-carbon fluxes: East River, Colorado (Watershed Function SFA)

## Decision

**INCLUDE.** The staged payload `Soil_water_content_Fig4e.csv` contains direct
volumetric water content (VWC) observations for three East River PLM sites,
satisfying the measurement-type rule (Rule 2). No experimental manipulation is
indicated; this is a natural hillslope monitoring record.

## Payload identification

Only one file is staged for this fold: `Soil_water_content_Fig4e.csv`. The full
package lists many other CSVs (sulfate fluxes, pore-water chemistry, 14C, water
table, etc.) and documentation (Methods PDF/DOCX, `dd.csv`, `flmd.csv`), but the
only soil-moisture payload — and the only staged file — is the VWC table. All
other package files are chemistry/flux data or documentation and are not soil
moisture observations.

## Source structure

- Wide format: `Date` column + one VWC column per site
  (`PLM1 _vol_water_content`, `PLM2 _vol_water_content`, `PLM3 _vol_water_content`).
- Second line of the file is a units row (`YYYY-MM-DD`, `m3/m3`); skipped on read.
- 103 measurement dates spanning 2017-05-06 to 2021-05-02.
- `-9999` used as a missing-value sentinel (4 occurrences).

## Time series determination

`is_timeseries = True`. Each PLM site has many observations at varying dates over
multiple years, consistent with a repeated monitoring record rather than a single
sampling campaign.

## Location resolution

Coordinates are **unresolvable** in this fold:
1. Payload — no coordinate columns.
2. Package ancillary files — not staged (only the VWC file is present).
3. Package ESS-DIVE metadata — provides only a watershed bounding box
   (NW 39.034, -107.05; SE 38.88, -106.88), not per-PLM-site coordinates.
4. Approved location registry — the referenced Varadharajan et al.
   (doi:10.15485/1660962) location dataset is **not staged** in this workspace,
   so it cannot be used.

All three sites are emitted in the location file with empty `latitude`/`longitude`
and `qc_flag = g2`. No coordinates were invented.

## Limitations / open questions

- **Depth:** measurement depth is not in the payload; the Methods document
  (`Wan_et_al_Methods.pdf`/`.docx`) that would describe sensor/sample depth is not
  staged, so `depth_m` is NA for all rows.
- **Timezone:** source dates are date-only with no stated timezone; Etc/GMT+7
  (US Mountain, no DST) was assumed for consistency with other East River datasets
  in this project. Resulting UTC timestamps carry a nominal 07:00 time-of-day.
- **Coordinates:** PLM1/PLM2/PLM3 coordinates could not be resolved from any
  supplied source (flagged `g2`).
