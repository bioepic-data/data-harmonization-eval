# Harmonization notes — ess-dive-61a0ecd70856892-20230808T205724993

- **Index:** 8 (retained from `MANIFEST.json`; not reassigned)
- **DOI:** doi:10.15485/1958210
- **Title:** Soil water content, matric potential, carbon dioxide and oxygen
  concentrations, Oct 2018–Dec 2021, Slate River Floodplain, Crested Butte, CO
- **Decision:** INCLUDE

## Payload identification
Eight staged files: four `*_data.csv` (one per calendar year) and four
matching `*_InstallationMethods.csv`. The data files are the measurement
payloads; the InstallationMethods files are sensor + location metadata
(serve dual role here — they carry both coordinates and sensor specs).
The package `dd.csv` / `FLMD.csv` dictionaries referenced in the metadata
were **not staged** in `inputs/raw/`; they are documentation only and are
not required for harmonization.

## Inclusion rationale (SKILL Section 3)
- Rule 1 (duplicate): no evidence of supersession; include.
- Rule 2 (measurement type): direct observations of volumetric water content
  (`SoilMoisture_*cm.m3.m3`) and soil matric potential (`SoilMatricPot_*cm.kPa`).
- Rule 3 (manipulation): none — ambient monitoring station; no treatment.
- Rule 4 (payload): parseable timestamped tables present.
- Rule 5 (metadata): coordinates resolved (see below).

## Variable mapping
- **datetime_UTC** ← `DateTime.MST`. Timestamps are Mountain Standard Time
  (UTC-7, no DST), localized with `Etc/GMT+7` and converted to UTC.
- **depth_m** ← depth integer/float embedded in each measurement column name
  (cm → m by ÷100). Depths: 0.40, 0.60, 0.825 m (VWC); 0.40, 0.60, 0.79,
  1.00 m (matric potential).
- **volumetric_water_content_m3_m3** ← `SoilMoisture_*cm.m3.m3`; already
  m³/m³, no conversion.
- **water_potential_kPa** ← `SoilMatricPot_*cm.kPa`; already kPa (negative),
  no conversion. Absent from the 2018 file (sensors installed Aug 2019).
- **gravimetric_water_content_gH2O_gs** ← not measured; set NaN.
- **replicate** ← no replicate encoding in source (single sensor per
  depth/variable); set to 1.
- **site_id** ← single station for the whole package; constant `SLT_OBJ2`
  (from file-name prefix; SiteName "Slate River OBJ-2").
- Non-target columns (SoilTemp, SoilBulkEC, SoilCO2, SoilO2, ScansPerRec,
  EnclosureTemp, BarometricPress, DataFlag_01) were dropped.

## Missing-value handling
Source sentinel `-9999` (and `-9999.0`) coerced to NaN and dropped from the
long table, so only real observations are emitted.

## Time-series determination (SKILL Section 4)
`is_timeseries = True` — continuous datalogger output at ~30-minute
intervals (Campbell Scientific CR1000X), ~195k observation-rows across the
four years. Note the documented winter 2019–2020 gap (power outage) and the
2021 file starting mid-May.

## Location resolution (SKILL Section 5)
Coordinates present in the data package itself (InstallationMethods files,
`Latitude`/`Longitude`, identical across every row and year) and corroborated
by the package `spatialCoverage` record: **38.90943, -107.028242** (decimal
degrees, WGS84). `qc_flag` left empty (coordinates fully resolved; not
approximated). One distinct `site_id`, hence one location row.

## Open questions / limitations
- Matric potential at 0.79 m vs VWC at 0.825 m are treated as distinct depths
  (as reported); they are not merged.
- Package dictionary files (`dd.csv`, `FLMD.csv`) were not staged; column
  interpretation relied on self-describing column names + package metadata.
- No daylight-saving ambiguity expected since the source labels time as MST.
