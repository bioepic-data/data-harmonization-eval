## Decision: INCLUDE

- RULE 2 (measurement type): The package contains direct soil moisture observations:
  `swc` (soil water content) and `swp` (soil water potential). Although this is a
  machine-learning manuscript package, swc comes from TEROS12 point sensors (direct
  observation). swp is derived from measured swc via a sensor-calibrated water-retention
  relationship; it is retained but documented as derived.
- RULE 4 (extractable payload): `df_data.csv` + `df_meta.csv` provide a parseable,
  row-aligned measurement table (1001 observation rows).
- RULE 3 (manipulation): The `tb` site is an outdoor mesoscale experimental testbed,
  but no treatment/control split is present in these two files; all four sites are
  reported as ambient daily observations. Included without exclusion.

## Payload identification

- `df_data.csv` — measurement payload. Columns: txmax, txmin, tomax, tomin, u, vpd,
  pa, precip, srad, nsrad, nlrad, rn, g, lai, **swc**, **swp**, xT, xu, h, ET.
  Only swc and swp are in the target soil-moisture schema.
- `df_meta.csv` — location/time file. Columns: site, datetime, year, doy.
  Positionally row-aligned with `df_data.csv` (provider states each row index
  corresponds). This serves as the location/time metadata source.
- Other package files (ipynb scripts, methods.py, sub_models/, df_data_dd.csv,
  df_meta_dd.csv, flmd.csv, README.txt) are **not staged** in this fold; only the two
  CSVs are available under `inputs/raw/`.

### Unit determination
- `swc`: values 0.104–0.395 are dimensionless volumetric fractions → m3 m-3. No conversion.
- `swp`: all 1001 values negative, magnitudes of a few to ~8400. This range is consistent
  with kPa for soil matric potential (wilting point ≈ -1500 kPa; droughted shrubland soils
  can exceed this). Not MPa (would be ~0 to -8) and not bar. Treated as kPa, no conversion.
  The data-dictionary file that would confirm units (`df_data_dd.csv`) is not staged in this
  fold; this is the documented assumption and the single most important open question.

## Depth

swc/swp are reported by the provider as depth-weighted averages integrated across four
sensor depths (ph1/ph2/sg5: -0.1, -0.3, -0.6, -1.15 m; tb: -0.1, -0.3, -0.5, -0.7 m).
Because no single representative depth exists, `depth_m` is set to NaN for all rows.
No `d1` flag is applied (depth is not approximated from a range; it is intentionally absent).

## Time series determination

`is_timeseries = True`. The data are continuous daily sensor statistics spanning
2019-10-12 to 2023-04-11 at each site, with many dated observations per site
(tb=449, ph1=275, ph2=148, sg5=129). Timestamps are daily (date-only), so time is
localized to midnight UTC. Rows were shuffled chronologically by the provider for ML
training and are re-sorted in the harmonized output.

## Open questions / limitations

1. **swp units** cannot be confirmed from a staged data dictionary (`df_data_dd.csv`
   not present in this fold). Assumed kPa based on value range; revisit if dictionary
   becomes available.
2. **depth_m is NaN** by design because reported soil moisture is a depth-integrated
   average. Confirm whether the pipeline prefers a representative depth instead.
3. swp is a derived variable (from swc via retention curve), not an independent
   observation; documented in the mapping `transformation` field.
4. ph1 coordinates in spatialCoverage are rounded (38.92, -106.95) relative to the
   more precise ph2/sg5/tb entries; used as supplied (no external lookup permitted).
