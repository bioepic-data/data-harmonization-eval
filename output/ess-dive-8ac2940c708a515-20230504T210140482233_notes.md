- **Title:** Microclimate observations associated with snowmelt experiment gradient sites, East River, Colorado, 2017 to 2020
- **Canonical index (from MANIFEST.json):** 5

## Decision

**INCLUDE.** The staged payload `SM_SWC.csv` contains direct volumetric soil
water content observations (RULE 2 satisfied) as a machine-readable hourly time
series (RULE 4 satisfied).

## Payload identification

Only `SM_SWC.csv` is staged in `inputs/raw/`. The package metadata lists four
other files (SM_ST.csv soil temperature, SM_AirT.csv air temperature, SM_rH.csv
relative humidity, Microclimate_Sensors.csv), none of which are staged. Of the
listed files, only `SM_SWC.csv` is a soil-moisture payload, so it is the sole
data payload used here.

## Time series determination

`is_timeseries = True`. Regular hourly timestamps per site spanning 2017-05-26
to 2020-10-23; the package describes a continuous microclimate sensor
deployment.

## Location resolution

Coordinates are **unresolvable** -> `qc_flag = "g2"`, empty `latitude`/`longitude`
for all 33 sites.

- No coordinates in the payload.
- Package metadata `spatialCoverage` provides only a watershed bounding box
  (NW 39.034/-107.05, SE 38.88/-106.88), i.e. corners of the study domain — not
  per-site points — so it cannot assign coordinates to individual sites.
- The sibling packages (e.g. index 23) resolve coordinates via the Varadharajan
  et al. location registry (doi:10.15485/1660962, index 0). That registry's data
  file is **not staged** in this fold, so it cannot be used.
- Per AGENT_INSTRUCTIONS, no coordinates were invented and no external lookup was
  performed. The `_location.csv` lists every `site_id` with empty coordinates and
  `qc_flag = "g2"`, as required.

## Experimental manipulation (RULE 3) — FLAGGED

This is an experimental **early-snowmelt manipulation** gradient study with
paired treatment/control plots (per package `measurementTechnique`:
pre-treatment 2017, treatment 2018-2019, post-treatment 2020). The sibling
warming package (index 23, `WM_SWC.csv`) filters to `Treatment == "control"`
using `plot_metadata.csv`. Here, **`plot_metadata.csv` is not staged** and the
payload carries no treatment column, so treatment and control plots **cannot be
separated**. Following RULE 3 (flag, do not auto-exclude), all plots are included
and the confounding is documented here and in the mapping JSON `transformation`
field.

## Limitations / open questions for operator review

1. **Depth unknown.** `sensor_metadata.csv` is not staged, so `depth_m` is NaN
   for all rows. (Sibling index 23 obtains depth by joining on `Sensor.SN`.)
2. **Treatment vs control not separable** (see RULE 3 above); all plots included.
3. **No coordinates** (`qc_flag = "g2"`); would resolve to `g1` if the
   Varadharajan registry were supplied in the workspace.
