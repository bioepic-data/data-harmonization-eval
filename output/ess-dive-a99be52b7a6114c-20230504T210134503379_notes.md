## Payload identification

- `WM_SWC.csv` — measurement payload: hourly soil water content, long format
  (`Date Time, Plot.Location, Point.Location, Veg, Sensor.SN, Sensor.Type, Measurement`).
  All payload rows have `Sensor.Type == "SWC"`.
- `sensor_metadata.csv` — ancillary; provides per-sensor `Depth.cm` keyed by `Sensor.SN`.
- `plot_metadata.csv` — ancillary; maps each plot (`Plot.Location`) to warming
  `Treatment` (`control` / `heated`).
- `WM_ST.csv` — soil **temperature** payload, listed in package metadata but not
  staged in `inputs/raw/` and not relevant to the soil-moisture schema; not used.

## Key decisions

1. **Warming manipulation (RULE 3 / general insight #10).** This is an IR-heater
   warming experiment with alternating control and heated plots. Per the skill,
   a manipulation experiment is flagged and documented, not auto-excluded.
   Control and heated records are both retained; treatment is documented in the
   mapping JSON so heated plots (`ER-WM2/4/6/8/10`, i.e. `Point.Location`
   suffixes 2/4/6/8/10) can be filtered downstream for an ambient-only signal.

2. **site_id = Point.Location.** Chosen over `Plot.Location` because each plot has
   distinct upper (`...U`) and lower (`...L`) sensor zones that differ in soil
   moisture and map 1:1 to the sensor metadata. Yields 20 distinct sites.

3. **Depth via Sensor.SN join.** Depth is sensor-specific (6 or 14 cm), so it is
   resolved by joining each payload `Sensor.SN` to its `Depth.cm` in
   `sensor_metadata.csv`, then converting cm → m. Not a reported range, so no
   `d1` flag is applied.

4. **Units.** Soil water content is already volumetric (m³/m³); no conversion.

5. **Replicate.** Multiple SWC sensors are co-located at the same point and depth;
   replicates are numbered 1..n per (datetime, site_id, depth_m).

## Limitations / open questions

- **Coordinates unresolvable → `qc_flag = "g2"` for all 20 sites.** No per-site
  coordinates exist in the payload or ancillary files; the package metadata
  carries only a watershed-level bounding box (NW 39.034, -107.05 / SE 38.88,
  -106.88), not per-site `GeoCoordinates`. The referenced location registry
  (Varadharajan et al. 2020, doi:10.15485/1660962) is **not** supplied in this
  workspace, so `g1` cannot be assigned and coordinates were not invented.
- **36 payload rows (one SWC serial number) have no recorded depth** in
  `sensor_metadata.csv`; `depth_m` is left NA for those rows.
- **Timezone** assumed Mountain Standard Time (fixed UTC-7), consistent with the
  sibling RMBL package (index 5, DOI 1842907) and the regional convention used
  for East River SFA loggers; the package does not state the offset explicitly.
- **10 exact-duplicate (time, Point.Location, Sensor.SN) rows** exist in the raw
  payload; they are retained and separated via the replicate counter rather than
  dropped, to avoid silently discarding source records.
