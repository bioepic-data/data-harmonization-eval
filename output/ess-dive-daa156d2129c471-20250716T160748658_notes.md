# Harmonization notes — ess-dive-daa156d2129c471-20250716T160748658 (index 24)

Daily water stable isotopes, transpiration, and matric potential data for an
aspen and Engelmann spruce stand in the East River Watershed near Gothic, CO
(doi:10.15485/2462766).

## Inclusion decision

**INCLUDE.** The payload contains direct observations of soil matric (water)
potential, which maps to the target variable `water_potential_kPa` (Rule 2
satisfied). Matric potential was measured with Teros 21 sensors (accuracy
±(10% of reading + 2 kPa) from −100 to −5 kPa) along two soil profiles.

## Payload identification

- `Iso_MP_Sap_DataDaily_ESSDiveUpload_R1.csv` — the measurement payload
  (semicolon-delimited, 956 daily rows, 406 columns). Only the six
  matric-potential columns `P1_MP_15`, `P1_MP_30`, `P1_MP_60`, `P2_MP_15`,
  `P2_MP_30`, `P2_MP_60` map to the soil-moisture schema. 534 rows carry
  matric-potential values.
- All other columns — stable isotopes (`d2H_*`, `d18O_*`), sap flow
  (`SapFlow*`, `TMax_*`, `TSum_*`), meteorology (`Precip_mm`, `Tair`,
  `RelHum`, `BarPress_mbar`, etc.), and isotope profile columns
  (`A*`/`S*` depth columns) — are not VWC, GWC, or water potential and were
  not harmonized.
- `Locations.csv` — location metadata (semicolon-delimited) with `ID`,
  `Latitude`, `Longitude` for the instrumented trees (A1–A3, S1–S3) and the
  two soil/isotope profiles (P1, P2).
- `dd_R1.csv`, `flmd.csv`, `Locations_LDRD.kmz` — units dictionary, file-level
  metadata, and KMZ map; these are documentation/ancillary files and were not
  staged in `inputs/raw/`.

Wide-to-long reshape of the six MP columns produced 3,204 harmonized rows
(534 dated observations × 6 profile/depth combinations after dropping missing
values).

## Time series determination

`is_timeseries = True`. The dataset is an explicit daily time series from
continuous 10-minute sensor deployments aggregated to daily values over
2022-06-16 to 2024 (metadata temporal coverage 2022-06-15 to 2024-07-14).

## Location resolution

Resolved from the package ancillary file `Locations.csv` (priority 2). Both
MP profiles are present:
- P1 (aspen soil/isotope profile): 38.96071917, −106.9910977
- P2 (spruce soil/isotope profile): 38.96067806, −106.9910133

Per the metadata measurement technique, the matric-potential sensors were
installed within ~30 cm of the P1/P2 isotope vapor probes, so the profile
coordinates in `Locations.csv` apply to the MP profiles of the same name.
Both sites resolved, so `qc_flag` is empty (not `g1`/`g2`). The required
`_location.csv` lists one row per distinct `site_id` (P1, P2).

## Units / QA

- Matric potential reported in kPa (negative); no conversion applied.
- Depth converted cm → m.
- Timestamps converted to UTC from America/Denver.
- Empty-string cells in the semicolon-delimited payload parse to NaN; rows with
  no matric-potential value were dropped from the harmonized output.
