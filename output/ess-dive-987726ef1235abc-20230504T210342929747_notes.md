# Harmonization notes — dataset index 15

- **Dataset:** `ess-dive-987726ef1235abc-20230504T210342929747`
- **DOI:** doi:10.15485/1648526
- **Title:** Time-domain reflectometer survey across the East River Watershed, Colorado (WFSFA)
- **Payload file:** `TDR_survey_ER_20190701.csv` (101 survey points)

## Payload identification (STEP 2)
A single CSV (101 survey points) is supplied; it is the measurement payload. It
also contains the location metadata (UTM coordinates per point), so it doubles
as the `location_metadata_files` source. No separate README, sensor, or
ancillary file is present in the package.

## Inclusion/exclusion decision (STEP 3)
**INCLUDE.** Rule 2 (measurement type) is satisfied: the file reports direct
volumetric water content observations (`TDR_SM(VWC%)_1..3`) measured with a
25-cm time-domain reflectometer probe. Not superseded/duplicated (Rule 1),
payload is machine-readable (Rule 4), and coordinates are present (Rule 5).
Soil temperature and electrical conductivity columns are out of schema and were
dropped.

## Variable mapping (STEP 4)
- **site_id** ← `GPS_id` — the stable per-point RTK-GPS identifier (unique for
  every row; 101 points incl. `ss*` and `TDR*` series). `Site` (Pumphouse,
  Bradley 1/2, Snodgrass) is a hillslope grouping, not a unique point ID, so it
  was not used as `site_id`. `Sample_id`/`id` are sparsely populated and partly
  empty, so `GPS_id` was preferred.
- **volumetric_water_content_m3_m3** ← `TDR_SM(VWC%)_1`, `_2`, `_3` — three
  replicate TDR readings per plot; melted wide→long and divided by 100 (% →
  m³ m⁻³). Empty replicate cells (some later `TDR*` points have only one reading)
  are dropped, leaving 286 observations across 101 sites.
- **replicate** ← integer suffix 1/2/3 parsed from the VWC column names.
- **depth_m** = 0.25 — fixed; metadata states a 25-cm TDR probe. This is a
  reported fixed depth, not an approximated range, so **no `d1` flag**.
- **is_timeseries** = False — discrete sampling campaign (early July 2019), a
  single visit per point; no monitoring frequency or repeated timestamps.
- **gravimetric_water_content_gH2O_gs**, **water_potential_kPa** = NA (not
  reported).

## Timestamp (STEP 5 / limitation)
The payload has **no per-observation date/time column**. Package metadata only
gives a campaign window (`temporalCoverage` 2019-07-02 → 2019-07-07; file name
suggests 2019-07-01). Rather than invent per-row timestamps, `datetime_UTC` is
left empty (NA). This is a documented limitation of the source.

## Location resolution (STEP 6)
- Source: coordinates in the payload file itself (priority 1).
- Columns `Easting_m` / `Northing_m` are UTM. Package `measurementTechnique`
  explicitly states **EPSG:26913 (NAD83 / UTM zone 13N)**, so reprojection uses
  EPSG:26913 → EPSG:4326 (not the 32613/WGS84 helper in `common.py`).
- All 101 points resolved to lat/lon; resulting coordinates fall inside the
  dataset's declared bounding box (38.88–39.034 N, -107.05 to -106.88 W).
  `qc_flag` is empty for all sites (coordinates resolved; not `g1`/`g2`).
- `*_location.csv` contains one row per distinct `site_id` (101 rows = 101
  distinct `GPS_id` values; no duplicate GPS_id in the payload).

## QA (STEP 9) / open questions
- VWC values range 0.0–0.495 m³ m⁻³ after conversion — physically plausible for
  near-surface soil (a few high replicates near 0.495 retained as reported).
- Zero EC values and some blank first-replicate cells were left as-is / dropped
  per the rules above.
- Depth is a single metadata-derived value; if plot-specific probe insertion
  depths existed they are not in the package.
- Missing per-row timestamps are the main gap; flagged for operator review.
