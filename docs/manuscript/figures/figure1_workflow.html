Figure 1. Current leave-one-cluster-out evaluation workflow.

Each run builds a self-contained, answer-free workspace for one held-out target: the target's cluster is removed from the exemplar mapping and expert-code references, only the target raw files and metadata are staged, and the agent writes all deliverables under output/. After the run, an invigilator audits the tool trace for out-of-bounds reads and a trusted scorer compares the agent's executable output to the expert BERDL reference.
