1 · Design

What is being compared

Each fold hides one dataset from the agent's reference material, gives it that dataset's raw files, and asks it to harmonize them. We compare the output against the expert's harmonized version of the same dataset.

2 · Primary metric

Output equivalence — specification

Matching rows on (timestamp, site, depth, replicate) alone is misleading: a site-naming difference or a uniform clock offset sends the score to zero while every value is correct. Four levels are computed and all four reported.

LevelJoin keyIsolatesDegenerate when
L0none — distributions onlyunit errors, row-count errorsnever
L1datetime + depth + replicatevalue accuracy, site naming set asideclock offset
L2L1 + site, after reference→agent name crosswalksite identity modulo vocabularycrosswalk fails
L3datetime + site + depth + replicatestrict headlineany naming or clock difference
Inputs
Agent harmonized CSV; reference slice for the same dataset.
Row pairing
Keys are not unique (many sites share a timestamp). Both sides are sorted deterministically and the n-th occurrence within a key is paired with the n-th. Multiset semantics; row order is irrelevant.
Outputs
precision = matched / n_agent, recall = matched / n_gold, F1, and cell agreement over paired rows (numeric within rtol 1e-5 / atol 1e-8; text exact).
Interpretation
High L1 with zero L3 ⇒ correct data under different labels. Low L1 ⇒ genuinely wrong values. The gap is the diagnostic.

4 · Schema conformance

Specification and results

Checks
All 8 columns present · no extras · correct order · required fields populated · values within range (VWC 0–1, water potential ≤0, depth 0–100 m).
Deliberately not scored
Raw pandas dtypes. A CSV has no types; what pandas infers on read is a property of the reader, not the agent. Scoring it would mark every run wrong for storing a timestamp as text. Coercibility is scored instead: does every value parse into its intended type without loss?
Deviation from the repo helper
TargetSchema.is_valid() ignores range violations — a VWC of 95 passes it. Ranges count toward the verdict here.

6 · Documentation

Specification

Exact text matching is worthless here — the earlier pilot found 0/8 agreement on wording while the executed outputs were identical. "Does the text describe the same operations?" is answerable.

unit_conversion — not prose
153 reference values collapse to 9 templates once numerals are masked. Parsed deterministically by regex into (factor, from_unit, to_unit) and scored exactly. No judgement.
transformation — step extraction
Reduced to the operations it names from a 13-term controlled vocabulary (JOIN, FILTER, RENAME, TIMEZONE, PARSE_DATETIME, RESHAPE_WIDE_LONG, ASSIGN_CONSTANT, …). Lexical, applied identically to both sides so extraction bias is symmetric.
Pooling
Steps pooled per dataset, not per variable group — a filter governing every column is recorded inside the depth group upstream, so group-wise comparison would miss it.
Weighting
Unweighted, stratified by operation. FILTER appears twice in 153 reference patterns yet drives the largest output errors; any frequency-weighted average makes it invisible. Small cells reported as counts, never percentages.
Sources
Recall pools mapping text with notes.md; precision stays attributed per artifact.
An LLM extractor would recall more but must first be validated — blind to which text is the reference, never shown the output data, k-repeat self-consistency, and human IRR on a subsample. An LLM judging LLM-written text has a self-preference bias.

8 · Interpretation

How to read these statistics

LimitConsequence
Folds are not independent. Six of 19 are the same micrometeorology cluster.n=19 overstates the evidence; the pre-registered cluster bootstrap resamples only 3 units.
No error bars. Every fold is a single run; two accidental repeats differed by 3.9% of rows.Per-fold scores are point estimates of unknown precision. Fold-to-fold differences below ~4% are not interpretable.
Ablation is confounded with dataset type and difficulty.Exploratory only; not a finding.
One expert, not ground truth.Disagreement means divergence from that expert's conventions.
Prose scoring is lexical.Recall is a lower bound; an LLM reader would find more, once validated.
Coverage is uneven. Gravimetric water content is non-null in 416 of 6.4M reference rows.Its perfect agreement is vacuous and must not be reported as a capability.

Accordingly: per-fold detail and effect sizes rather than p-values, and any composite shown beside its components rather than instead of them.
